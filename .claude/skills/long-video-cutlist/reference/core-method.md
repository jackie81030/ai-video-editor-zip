# 選段核心方法（共用）

**這份檔案在 `reel-cutlist` 和 `student-cutlist` 裡一字不差。** 頭家自家用的選段方法，就是給學員的選段方法，學員版只是把「素材、理想客戶、敏感資訊」換成學員自己的。

- 母本在 `reel-cutlist/reference/core-method.md`。要改方法就改母本，再跑 `templates/學員選段-學員包/build.sh`，它會把母本複製到 `student-cutlist` 並檢查兩份一致。
- 各 skill 的 SKILL.md 是「情境層」：誰的素材、ICP 是誰、敏感資訊擋什麼、輸出長什麼樣。情境層可以加規則，不可以改掉這份裡的規則。
- 下面寫「專家」指的是片子的主角：`reel-cutlist` 是教練（Tao），`student-cutlist` 是學員本人。寫「理想客戶」指的是那支 skill 情境層定義的受眾。

版本：v1（2026-09-24）。從 reel-cutlist v3 抽出來，加上 2026-09-23 學員D上海素材那次 教練 的退件意見（字卡要講出這支的答案、訪談開頭保留問答、先定收尾再往回拉、整份當故事讀）。

v2（2026-10-17）：2026-10-15 一對多 Q&A 選段做了四版，教練 逐版退件的意見：先當選題師畫全場地圖再選段、開頭的來源順序和陌生人測試、開頭問的問題片子裡要回答到、中間的推理不砍、穿插別處的句子要讓陌生人跟得上、照專家講的順序剪、自檢時逐句唸一遍。

## 0. 這個方法只挑段，不剪片

輸出是一份剪輯師照著做的清單。多數時候只讀逐字稿、看不到畫面：安靜發生的好畫面（客人看鏡子不說話、無聲的成果揭曉）找不到，要特別留意周圍的反應句（「哇」「天啊」「跟我想的不一樣」「你看這邊」），並在清單最後提醒剪輯師可以自己補。

## 1. 先當選題師：整份讀完，畫出全場地圖，再選段

**你是選題師、企劃，不是找金句的人。** 像人看長影片一樣從頭看到尾，知道每個問題為什麼被問、前後怎麼接，整套故事融會貫通之後才開始選題。只看答案附近那幾句，選出來的片會沒頭沒尾（2026-10-15 一對多 Q&A v1：開頭都抓在答案旁邊，陌生人聽不懂）。

**先讀完，再動手。** 好段落藏在中間。宣告「這場沒東西」或交件之前，先寫出讀到第幾分鐘、總共幾分鐘。沒讀完不准下結論。

**當故事讀，不要逐句挑金句。** 逐句挑金句會把一段對話切碎：問題和答案被拆開、自然的開頭被當成鋪陳砍掉、整段沒被讀到的內容直接漏掉（2026-09-23 上海素材：訪談裡「第一次飛上海會不會怕」整段漏選，那正是理想客戶最大的顧慮）。

**先切段落（arc），再從段落裡挑片。** 由上往下把整份拆成一個個 exchange，每個記：誰在講、什麼引發的（當事人原本問的那句，記原話）、因果鏈（例：專家問 → 客人講自己的狀況 → 專家診斷或糾正 → 客人反應）。**一支片 = 一個完整段落或乾淨的子段落，絕不是半個 exchange。**

**選段前先寫全場地圖，放在清單最上面。** 後面每一步都從這張地圖拿材料：

- **這場在講什麼：** 一段話，整場的故事。
- **反覆出現的主題：** 同一件事被問了幾次、在哪些時間碼。
- **問題清單：** 每個段落裡，當事人自己問的那句原話（有數字、有情境的優先），附時間碼。
- **重整清單：** 專家幫當事人把問題講清楚的那句（「所以你是想要了解說…」「所以你是擔心說…」「你說 CTA 要說什麼，是不是？」），附時間碼。
- **最完整的一個故事：** 一個人的問題從頭解到尾的那段。

**同一段錄影可能有兩個機位或重錄。** 內容幾乎一樣的兩個檔，挑轉錄較乾淨的當主檔，另一個標成第二機位。

**轉錄雜訊。** 同一句重複幾十次、或一個無關的詞每隔一段冒出來（「字幕志願者」「詞曲 李宗盛」「生抽」），那段是沒人講話，雜音被誤轉成字。不要從那段選片，在清單裡標成可用的空鏡。

**砍太兇的三種，不要犯：** 只因為行業不對就砍、只因為沒數字就砍、只因為長度超了就砍。

## 2. 每一支先寫「這支在講什麼」

挑鉤子、定剪點之前，先用一兩句話寫出**這支片的核心**：理想客戶看完帶走的那件事，以及專家的答案是什麼。

- 寫得出來，後面的鉤子、字卡、剪點全部對準它。
- 寫不出來，代表這段還沒想清楚，或它根本不是一支片。
- 這句要寫進清單，放在每一支最上面。剪輯師和學員一眼就知道這支在講什麼，不用看完影片才懂。

例（2026-09-23）：片子開頭在講「大家都搶名醫」，但這支的核心是「專家全程跟，不會被換刀」。只寫「搶名醫」的字卡，觀眾看完才懂在講什麼。

## 3. 專家是主角

片子的價值是專家的專業：解釋、糾正、診斷，或邊做邊說為什麼。

- **只有別人在講的一大段不算。** 客人獨白、學員自述，要接上專家的回應，不然不選。
- **只有反應沒有原因不算。** 「哇好漂亮」後面沒有專家解釋為什麼會這樣，不是一支片。
- **見證不能單獨成一支。** 客人講自己多滿意，要有專家的判斷或做法在片子裡（專家說過的話由客人轉述也算，例：「你跟我說要稍微拉一下眼尾」）。
- 專家一個人對鏡頭講的錄影，自動過這關，但一樣要過四段結構和教育鐵律。
- 片子裡專家戲份不夠、但段落本身很好，可以列「要補一段」，寫清楚請專家補錄哪一句的**題目**。補錄的內容讓專家自己講，清單不要替他寫台詞。

## 4. 四段結構（每一支都要有）

缺一段就還沒好：要嘛從別處跳剪補進來，要嘛標「要補一段」。**缺兩段以上就不選。**

1. **開頭鉤子：點出「給誰看」＋核心。** 前三秒讓理想客戶覺得「這在講我」。
2. **問題：** 有人把問題講出來。最好是當事人自己講（學員提問、客人說自己的狀況），其次是專家點出他看到的問題。這段常常不在答案旁邊，要往前後找，用跳剪接進來。
3. **方法：** 具體做法或步驟，最好有名稱，不用細講完，吊出「用這個方法能做到什麼」。
4. **收尾：** 一句能單獨成立、能定格的話，講到結論，不收在半句、不收在下一支的開頭。

**四段要接得起來：**

- **開頭問了什麼，片子裡一定要回答到。** 開頭是「一天發兩支還是一支？」，片子裡就要有專家對這題的回答，不能只講旁邊的道理（2026-10-16 v2：整支在講「不用怕被嫌煩」，開頭的問題沒回答）。
- **專家講了順序，就照順序剪。** 他說「這是第一步，第二步就是…」，不要拿他後面的總結（「就兩個方向」）把它剪成兩個並列的選項（2026-10-17 v3）。
- **中間的推理不砍。** 「為什麼」「怎麼做」和專家舉的例子，是觀眾聽得懂的關鍵。為了壓秒數砍掉，片子只剩結論（2026-10-16 v2：CTA 那支砍掉「這樣聽的人才可以判斷：我是不是這種人」，觀眾跟不上）。推理需要多長就多長，不為了秒數砍中間。超過 90 秒的在標題標「偏長，約 X 秒」，交給剪輯和校稿的人決定怎麼收（2026-10-18 教練 定）。

**教育鐵律：** 每一支都要寫得出下面其中一句，寫不出來就降一級：

- 「理想客戶看完，下次遇到［具體情境］會改成［具體做法］。」（行為改變）
- 「理想客戶看完，會第一次意識到［某個認知］。」（認知突破）

再問一次：他會不會轉發給別人，或珍藏起來下次再看？教得越具體越過得了這關，模糊的雞湯只會被滑過。

## 5. 先定收尾，再往回拉

**先找這支要停在哪一句**（通常是專家的結論，或客人講出最有力的那句），再往回找能鋪到那一句的材料。材料可以來自整份錄影的任何地方，不限於收尾旁邊，用跳剪接起來。

這一步專門擋「段落看起來太短、太單薄」：單看一小段不夠，但整份訪談裡常常有別處的話可以補進來（2026-09-23：「我自己做美容，眼睛真的做不來」當收尾，往回拉了訪談裡「看眼睛就顯老」「其他地方保養得還 OK」「年輕至少五歲」三段，一支單薄的片變完整）。

**素材可以從錄影任何地方穿插。** 專家在別的問題講過、剛好合適的句子，可以剪進來用。條件只有一個：陌生人跟得上。一支片要有一條主線（一個問題 → 答案），穿插進來的句子是幫這條主線講清楚（2026-10-16 v2：CTA 那支剪了四個行業的例子，每個都換一個人、沒有解釋，陌生人跟不上。問題出在跟不上，不是不能穿插）。

## 6. 鎖開頭：先給 2-3 句候選，自己挑一句

**開頭從全場地圖找，照這個順序：**

1. 當事人自己問的具體問題（「這一支破到 10 萬觀看，但轉單率很低，是我鉤子的問題嗎？」）。
2. 專家重整的那句（「所以你是擔心說，你一次發超過一支，大家會覺得你很煩？」）。
3. 專家的結論句。前兩種都找不到才用。

問題常常在答案前面好幾分鐘（學員一上台就講了），用跳剪接過來。

在動其他剪點之前，挑出開場那句**原話**（可以跳剪自錄影別處），逐字寫下來，附一句為什麼選它。再找 **1-2 句備案**，一起寫進清單。備案是給校稿的人直接換用的：換一句話幾秒鐘，重寫一支要十幾分鐘。過不了檢查的句子不要拿來充備案。

每一句候選都要過這張檢查（來自 Max 的退件紀錄，開頭被退 7 次的原因都在這）：

- **第一個字就是症狀。** 不留鋪陳（「就是說」「那我想問一下」「我們家是做⋯」剪掉）。
- **不放成果。** 開頭是見證或成果，觀眾沒理由看下去。
- **不是起源故事。** 「我三年前開始⋯」不是開頭。
- **是問題，不只是痛點。** 「好累」是痛點，「每天明明睡飽，看起來還是很疲憊」是問題。
- **四項都要有：** 主詞（誰卡住）、代價（損失什麼）、無行話（一般人聽得懂）、無懸空（不是講一半的句子）。
- **陌生人測試。** 前面什麼都沒看過的人，單聽這句也懂。不能有指不到的字：「剛剛」「這支」「那句」「中間」。真的需要上下文，用開頭字卡補，並在清單寫明（2026-10-15 v1：「你可以再講一次你剛剛說的視覺是什麼意思」）。
- **教學片直接點出問題本身。** 例：「太多專有名詞了」。不要從比喻、或講一半的例子開始（2026-10-17 v3）。

**訪談素材的例外：問答開頭。** 專家提問、當事人緊接著講出症狀的時候，**「問句＋回答」一起當開頭**，不要把問句當鋪陳砍掉，只留後面半句。問句替觀眾問出了他心裡的問題，回答第一句就是症狀，這是最自然的鉤子（2026-09-23：「你怎麼會想要來做眼睛？」「因為雙眼皮腫、拋，整天沒精神，看起來很老態」，比只留「每天明明睡飽」好）。條件：問句要短（一句），回答要馬上進症狀。問句很長或回答繞了一圈才講到重點，就照一般規則。當事人自己問的問題不受這條限制：可以長，用跳剪剪掉繞的部分，留有數字、有情境的那幾句。

鉤子句型沿用驗證過的爆款結構，只換行業用語，不要自己發明句型。

## 7. 開頭字卡 = 這支的主題句

**每一支都要有開頭字卡，字卡就是這支片的主題句**，對準第 2 步寫的「這支在講什麼」。

- 字卡要講出這支的**答案或立場**，不是只講開頭那段的背景。片子開頭是背景時（例：「大家都搶名醫」），字卡要把答案補上（「指定名醫，麻醉後開刀的卻是別人？所以我的客人我全程跟」），可以分兩行。
- 寫給理想客戶看，不是描述講者。
- 連著唸的一串條件（營收、淨利、人數）不要拆成多張字卡分開停，一口氣打完再停。數字逐字核對。

## 8. 定格點、保留停頓

- **定格點：** 除了收尾，另外挑出全片最利的一句（常常在方法段），標「停一拍、上大字卡」。
- **保留停頓：** 講到關鍵處（講出數字前、講出結論前）停的那一兩秒常常就是鉤子，剪輯習慣會修掉。看到就明講「XX 那兩秒不要剪，因為⋯」。

## 9. 批評別人的話：一定標出來

片子裡出現批評同行、員工、客人的話（就算是原話），**一定要在清單裡標出來，寫出是哪一句、風險是什麼**（被點名、被檢舉、客訴），並找找同一段裡講者自己講的正向版本當替代。

要不要因此不出這支，看情境層：有的情境（例：頭家的廣告）是硬關卡，過不了就不出；有的情境（例：學員版）只提醒，由學員自己決定。沒寫的情境，預設只提醒。

## 10. 講者不准用推的

每一句字幕都要標講者。

- 有畫面：看畫面事實判（名字標籤、發言框、嘴型）。**不准用推的，不准用音高判。**
- 只有逐字稿：從內容判得很確定才標；不確定的標「（？）」並在清單寫「講者待剪輯看畫面確認」。**主角是不是專家本人，影響這支過不過第 3 步，所以標「？」的片要在清單裡講清楚這件事。**

## 11. 評分與分級

每支標三個訊號，有／沒有：

- **金句收尾：** 有一句可以定格的話。
- **張力或畫面：** 當事人被戳中，或一個好懂的比喻。
- **具體真人或數字：** 真的案例、真的數字（可公開的）。

分級：

- **可以直接剪（Tier 1）** = 四段齊全（或能靠跳剪湊齊）＋至少 2 個訊號。
- **要補一段（Tier 2）** = 有力但缺一段，或需要專家補錄一句，或要收更緊。
- **缺兩段以上不選。** 不要為了湊數量硬塞。
- **同一段的兩半合成一支。** 問題和解法、道理和例子，是同一個 exchange 就是同一支，不要拆成兩支單薄的。

## 12. 引用只能是原話

所有引用只能用逐字稿裡真的有的話。可以刪贅字和口頭禪，**不可以加字、不可以改意思**（連一個連接詞都不行）。轉錄錯字（同音字、簡體）改成繁體正字，並在引用對照表標出原文和修正。材料不夠就寫平的，不補戲、不編數字，講清楚缺什麼。

讓陌生人聽不懂的原話可以整句刪掉（例：「我的極限可能就在眉峰了」），只要刪完意思不變（2026-10-17 v3）。

## 13. 驗時間碼

自動轉錄的時間碼會漂。挑完之後，回 SRT 撈出每個邊界句（和每段跳剪）的真實起訖：

```python
blocks=open("PATH/TO/file.srt",encoding='utf-8').read().split("\n\n")
idx={}
for b in blocks:
    lines=[l for l in b.splitlines() if l.strip()]
    if len(lines)>=2 and lines[0].strip().isdigit() and '-->' in lines[1]:
        n=int(lines[0]); s,e=[x.strip() for x in lines[1].split('-->')]
        idx[n]=(s,e," ".join(lines[2:]))
def tc(x):   # "00:25:37,680" → "25:37.7"(到 0.1 秒;超過一小時 → "1:02:03.4")
    h,m,rest=x.replace(",",".").split(":"); sec=round(float(rest),1)
    if sec>=60: sec-=60; m=int(m)+1   # 59.96 進位
    return (f"{int(h)}:{int(m):02d}:" if int(h) else f"{int(m)}:")+f"{sec:04.1f}"
want=[104,124,127]  # 邊界字幕的編號
for n in want:
    if n in idx:
        s,e,t=idx[n]; print(f"{n:>4} {tc(s)}-{tc(e)}  {t}")
```

**時間碼一律寫到 0.1 秒（`25:37.7`），不要砍成整秒。** 剪輯師在剪輯軟體裡要照這個數字找位置，剪輯工具（`cutlist_to_edl`）也直接讀它；只寫到秒，兩邊都要在前後一秒裡猜。開始 = 第一句的 SRT 起點，結束 = 最後一句的 SRT 終點，四捨五入到 0.1。不要寫到 0.01：自動轉錄本身會漂 0.2-0.5 秒，最後一位是假的精準（2026-09-30 教練 定）。

沒有時間碼的逐字稿，用「第一句原話 → 最後一句原話」定位，不要生出秒數。清單裡寫清楚剪點是哪一級（到 0.1 秒／靠原話定位），下刀以影片為準。
